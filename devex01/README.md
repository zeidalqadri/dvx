# DevEx01 - Chrome Extension for Intelligent Web Scraping

## 🚀 **Production-Ready Chrome Extension**

**DevEx01** is a complete intelligent web scraping Chrome extension with automated Google Sheets integration.

### ✨ **Core Features**
- **Intelligent CSS Selector Ranking** - Smart algorithm identifies best selectors
- **Automated Google Sheets Creation** - Professional reports for massive data
- **Product Table Generation** - Structured data with primary keys  
- **Image URL Extraction** - Product image analysis and validation
- **E-commerce Optimization** - Designed for product data extraction

### 🎯 **Quick Installation**

1. **Load Extension**: `chrome://extensions/` → Load unpacked → Select this folder
2. **Configure OAuth**: See `documentation/GOOGLE_SHEETS_SETUP.md`  
3. **Start Scraping**: Visit any e-commerce site and click DevEx01 icon

### 📊 **For Massive Data Processing**

DevEx01 is designed to handle **100s of pages** of extraction data by processing in the cloud via Google Sheets instead of crashing the browser.
